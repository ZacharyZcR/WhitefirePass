# 罪孽之网：山灵召集这十五个人的理由

> 第二版。原则：不推翻任何已经写定的身世，只在每个人那桩罪的"另一端"接上同桌的人。
> 游戏数据在 `src/lib/sins.ts`。

## 真相的形状

十五个人互不相识，却都欠着彼此的血。把他们串在一起的是**佩恩银行的钱**：

- 二十年来，佩恩父子银行在背后放款、收债。
- 阿什福德家在前台开矿：米德兰的灰谷煤矿、德兰士瓦的金矿。

这门生意留下的血债，最后都汇到**一个雪夜**。

**1912 年 11 月，伦敦切尔西，佩恩宅。**
那一夜，宅子里死了两个人：
- 老埃德蒙·佩恩中风倒在书房里，身边只有情妇夏洛特。
- 他的小儿子朱利安从楼梯上摔下来，断了脖子。

在场的每个人都只看见了一部分，也都隐瞒了一部分。

山灵在这一夜的周年召集了他们。

| 时间 | 事 |

| 1900 | 德兰士瓦。一支护送阿什福德矿车的连队遭伏击，三十二人全灭。死者里有夏洛特的父亲和艾米莉的弟弟 |
| 1903 | 伦敦。药剂学徒贴错了糖浆的标签，诺拉的母亲死了。她父亲是灰谷煤矿的安检员，从此酗酒，在一份安检报告上签了假字。同年三月灰谷塌方，十二人被埋 |
| 1907 | 曼彻斯特。本杰明的作坊辞退了一个咳血的女工，她是克莱尔的母亲。克莱尔十三岁，被送进伦敦佩恩宅当女仆 |

## 佩恩宅之夜

| 人 | 那一夜 |
|---|---|
| 夏洛特 | 老佩恩在书房里中风，她先把首饰和信收进手袋回了房间，过了将近一个钟头才去叫人。托马斯就是在这一个钟头里进的书房 |
| 托马斯 | 他在佩恩银行挪用公款，那晚来求老佩恩别告发。他在书房地上看见还有气的老人，没有叫人，先撬了保险柜，抽走了记着自己的那几页账 |
| 克莱尔 | 醉酒的小少爷朱利安在楼梯顶堵住她，她推开了他 |

| 亚历山大 | 替东区老板来向朱利安收赌债，在走廊上看见了这一切。他什么也没说，只记进了账本 |
| 奥利弗 | 佩恩家的长子，被父亲看不起的那一个。管家打电话叫他回家配药，他在药房里坐了一个钟头才动身 |
| 莉迪亚 | 不在场。朱利安小时候是她一手带大的学生。死因调查时，她写信说他本性温和，让陪审团认定女仆蓄意行凶 |
| 艾琳 | 不在场。几周后，那个逃亡的女仆躲到了她的小镇，她为了赏金去告发 |

## 十五人：各自的罪

"知情"分三档：
- **全知**：知道自己做了什么，也知道害了谁。
- **知事**：知道自己做了什么，不知道受害者是谁、就在身边。
- **不知**：连自己伤害过谁都不知道。

| 人 | 核心之罪 | 受害者 | 知情 |
|---|---|---|---|
| 塞缪尔 | 1893 年参与砸铺子，以为那一枪是自己这伙人开的，自己是凶手 | 托马斯、莉迪亚 | 知事 |
| 亚历山大 | 1893 年那一枪是他开的。他看着塞缪尔替他背了二十年的罪，还拿这个秘密从他的教区敛钱 | 托马斯、莉迪亚、塞缪尔 | 全知 |

## 牵连（较轻，或当事人不知）

- 本杰明：1893 年他在纽卡斯尔当船务文员，为了赏金向警察指认塞缪尔是开枪的人。塞缪尔：不知
- 维克多：战后报告把伏击推到向导头上，马库斯从此身败名裂。报告是文书照雇佣名单起草的，维克多在病床上签字时没看名字，所以认不出马库斯。知事
- 维克多：战后醉酒推倒怀孕的艾米莉，孩子没了。全知
- 艾米莉：在报告上替维克多作证，让马库斯背了全部的罪。知事
- 艾米莉：用一纸假伤情报告救下维克多，让他背着懦夫之名活下去。全知
- 塞缪尔：1893 年卷走了那晚收来的钱，亚历山大替他挨了老板的罚，从此给老板卖了二十年命。不知
- 托马斯：在佩恩银行拒批了本杰明 1908 年的贷款，把他推给了亚历山大。不知
- 托马斯：他挪用的窟窿，让银行收紧了阿什福德家的贷款。不知
- 伊莎贝拉：1911 年在社交圈散布阿什福德家资不抵债，引发挤兑。全知
- 亚历山大：他跟着本杰明上山，是盼着他死在这里——本杰明的人寿保险单押在东区老板手里。全知
- 亚历山大：逼诺拉的父亲还医药债。知事
- 奥利弗：给伊莎贝拉配过打胎药，她从此不能生育。知事
- 夏洛特：抢走了伊莎贝拉的资助人（就是老佩恩）。全知
- 克莱尔：朱利安一死，他欠东区老板的赌债也成了死账。老板把账算在亚历山大头上，派他来盯本杰明。不知

## 在游戏里

- **烙印者**：开局时，山灵把"谁害过你"的真相告诉他。第一夜，山灵会亲口对他低语，煽动他复仇。
- **背誓者**：第二天堕落时，同样得知这份真相。
- **所有人**：每个人心里都记着自己知道的那部分罪（全知、知事两档），但不知道受害者就坐在身边。
- **终局**：结局时揭开整张网。
